## Stack
- Laravel
- PostgreSQL
- Blade/Livewire
- Git/GitHub

## Rules
- Jangan menghapus file tanpa persetujuan.
- Jangan menjalankan command destruktif tanpa persetujuan.
- Jangan mengubah database production.
- Periksa konfigurasi Laravel sebelum menyimpulkan PostgreSQL bermasalah.
- Jika menemukan error, jelaskan penyebabnya sebelum memperbaikinya.
- Setelah melakukan perubahan, tampilkan file yang diubah dan alasannya.
